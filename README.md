# Lumen

An original browser light-routing puzzle. Six levels, mirrors, a branching prism, narrated story fragments and an original procedural Web Audio score.

Play: https://romangalaxys10-spec.github.io/lumen/

Gameplay: https://romangalaxys10-spec.github.io/lumen/Lumen_gameplay.mp4

Made for Chroma Awards Season 2, Game / Puzzle & Strategy.

AI assistance: Ira for code, puzzle generation, story and production. Microsoft Edge neural TTS (en-GB-SoniaNeural) for narration. All graphics rendered procedurally. No sponsor-tool award claimed.

No installation, dependencies, accounts or tracking. Open index.html in a modern desktop browser. Narration and music start after user interaction.
